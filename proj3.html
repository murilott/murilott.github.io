SecureUserAuth

Aplicativo para demonstrar a autenticação com tokens JWT (access e refresh tokens)

Projeto desenvolvido para aprender melhor o funcionamento de um sistema de autenticação com tokens JWT, baseado no projeto do HomeCHat

O usuário administrador é criado assim que o aplicativo sobe. É possível se registrar com email, nome e senha.

No login, tokens de refresh e access são emitidos e usados para autenticar as rotas, com excessão dos endereços liberados.

Um sistema de postagens foi implementado para demonstrar melhor o funcionamento dos cargos e da restrição de rotas. É possível apagar suas próprias postagens e o administrador pode apagar qualquer postagem.

Tecnologias:

  • Backend: Java/Spring Boot
  • Frontend: React/Typescript
  • Banco: H2 em arquivo local
  • Tokens JWT (access e refresh) para filtragem de rotas
  • Refresh token armazenado em cookies (HttpOnly)
Repositório do Github: github.com/murilott/SecureUserAuth
