NimbusMart

E-commerce baseado em microserviços inspirado na Amazon, utilizando React + TypeScript no frontend e Spring Boot no backend, com inventário, produtos, pedidos, entregas e pagamentos.

O projeto foi desenvolvido no Github Codespace, que já vem com docker configurado e permite rodar facilmente. No entanto, a limitação de horas mensais gratuitas atrasou a finalização do projeto.

É possível cadastrar produtos e fazer pedidos, simulando um sistema de pagamento, entrega e controle de estoque.

A parte de autenticação pode ser feita no futuro, com base no meu outro projeto, SecureUserAuth. Optei por não fazer para não aumentar o escopo do projeto, para não atrasar muito a finalização e para não pesar muito o Codespace.

O Redpanda foi escolhido por ser mais fácil de configurar e por ser mais leve.

Desafios

Implementar o gRPC e o Redpanda foram as partes mais chatinhas e demoradas.

Pontos de atenção:

  • Cada serviço tem sua própria responsabilidade e são independentes, respeitando os princípios do DDD.
  • A arquitetura hexagonal é utilizada para manter as classes organizadas e concisas.
  • As classes de domínio são independentes e utlizam somente anotações JPA (de banco), contendo as regras de negócio e validações necessárias.
  • Classes de DTO e entidade com responsabilidades bem separadas.
  • Em várias camadas são feitas validações e tratamentos de erros.
  • Utiliza-se gRPC para validação síncrona entre serviços ao criar entidades.
  • O Redpanda (Kafka) é responsável por enviar objetos de forma asíncrona, sinalizando mudanças de estado em outros serviços.

Serviços:

  • Produto: cria um produto com nome, descrição e tags
  • Inventário: recebe produto, quantidade e valor para criar um item no estoque, armazenado no Inventário
  • Pedido: recebe um item de inventário junto com a quantidade selecionada
  • Pagamento: recebe um pedido e um pagamento para confirmar a transação; cadastro de pagamentos
  • Entrega: recebe um pedido finalizado, orquestra as mudanças durante entrega
  • Frontend: responsável pelas telas que o usuário navega
  • Gateway-service: reúne os endpoints de todos os serviços em um só
  • Service-discovery: cadastra os serviços para que sejam utilizados pelo gateway, por exemplo

Possíveis implementações:

  • Autenticação: com tokens JWT e autenticação por cargo

Tecnologias:

  • Backend: Java/Spring Boot
  • Frontend: React/Typescript
  • Banco: H2 em arquivo local (para todos os serviços)
  • Docker: para subir e rodar os serviços
  • Comunicação síncrona: gRPC, com serviço de contrato compartilhado
  • Comunicação asíncrona: Redpanda (protocolo Kafka)
  • Maven multi-módulo: reúne todos os poms do projeto, permite importação para serviço de arquivos compartilhados(gRPC)
  • Script em Python para criar todos os diretórios em cada projeto automaticamente
