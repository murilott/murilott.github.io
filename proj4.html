QuadraJá

Aplicativo de aluguel de quadras feito com microserviços em Spring Boot, React e RabbitMQ.

Este trabalho foi desenvolvido para aula de Tópicos Avançados em Programação I. O projeto foi feito no Github Codespace, que já vem com docker configurado e permite rodar facilmente. No entanto, a limitação de horas mensais gratuitas atrasou a finalização do projeto.

É possível cadastrar quadras e fazer alugéis, simulando um sistema de pagamento e reservas.

É necessário criar um usuário. O login emite access tokens, porém as rotas não requerem autenticação por limitação de tempo.

Para comunicação entre serviços foi utilizado o RabbitMQ.

Serviços:

  • Quadra: cria quadras com preço, lugar e categoria
  • Pagamento: cadastro de pagamentos e adição de pagamentos à lista do usuário (logado)
  • Reserva: recebe uma quadra, data para reserva, pagamento e usuário. O pagamento tem que estar na lista do usuário para ser válido
  • Autenticação: com tokens JWT e autenticação por cargo; responsável pela criação de usuários
  • Frontend: responsável pelas telas que o usuário navega
  • Gateway-service: reúne os endpoints de todos os serviços em um só
  • Service-discovery: cadastra os serviços para que sejam utilizados pelo gateway, por exemplo

Tecnologias:

  • Backend: Java/Spring Boot
  • Frontend: React/Typescript
  • Banco: H2 em arquivo local (para todos os serviços)
  • Docker: para subir e rodar os serviços
  • Comunicação entre serviços: RabbitMQ
